# ShanShui: AI Emotional Landscape Game

A meditative browser-based 3D experience built with Three.js.

## Run locally

Because this app uses ES modules, run with a local static server:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Controls

- Click canvas to lock pointer
- Move: `W A S D`
- Look: mouse
- Type an emotion and press **Regenerate** to reshape the landscape
